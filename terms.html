← 散歩ルートに戻る

利用規約・免責事項

制定日：2026年10月7日

1. このサイトについて

散歩ルート（以下「当サイト」）は、出発地点・歩く時間・歩く速さから、出発地点に戻ってくる散歩ルートを自動で作る個人運営のサイトです。現在はβ版として公開しています。

2. ルートについて

  • ルートは地図データをもとに機械的に作っています。工事中の道、通行止め、私有地、歩道のない道路、階段、夜間に暗い道などが含まれる場合があります。
  • 表示される時間は、選んだ歩く速さから計算した目安です。信号待ちや坂道、寄り道の時間は含まれていません。
  • 実際に歩く際は、現地の標識・交通ルールに従い、周囲の安全を確認してください。歩きながらの画面操作は避けてください。
  • 体調や天候に合わせて、無理のない範囲でご利用ください。

3. 免責事項

当サイトのルートや情報を利用したことで生じた事故・損害・トラブルについて、運営者は責任を負いません。ルートの正確性・安全性・最新性は保証できません。

4. 位置情報の取り扱い

  • 「現在地を使う」を押した場合に限り、ブラウザを通じて現在地を取得します。取得した現在地は、出発地点の指定と、近い駅の表示にだけ使います。
  • 「ルートをつくる」を押すと、出発地点の座標と距離の条件を、ルート計算のために次のサービスへ送信します。
    • Cloudflare, Inc.（Cloudflare Workers：送信を中継するため）
    • HeiGIT gGmbH（openrouteservice：ルートを計算するため。ドイツの事業者です）
  • 運営者は、出発地点の座標や現在地を記録・保存しません。ただし、上記のサービスが自社の規約にもとづいて通信の記録を保持する場合があります。
  • 当サイトはアカウント登録がなく、氏名やメールアドレスなどの個人情報は取得しません。

5. データのライセンスと出典

  • 地図とルート計算に使う道路データは © OpenStreetMap contributors の著作物で、Open Database License（ODbL）で提供されています。
  • ルート計算には openrouteservice（HeiGIT gGmbH）を利用しています。
  • 駅のデータは、運営者が運営する「カフェナビ」と共通のものを使っています。掲載は東京都・神奈川県・埼玉県・千葉県の駅のみです。

6. 規約の変更

本規約は、必要に応じて予告なく変更することがあります。
